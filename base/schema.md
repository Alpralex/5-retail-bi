# Portal BASE — public contracts (IMPIC), 2019–2026

- Publisher: IMPIC — Instituto dos Mercados Públicos, do Imobiliário e da Construção
- Dataset: *Contratos Públicos - Portal Base - IMPIC - Contratos de 2012 a 2026*
  https://dados.gov.pt/pt/datasets/66d72d488ca4b7cb2de28712/
- Downloaded: 2026-10-25 (yearly `contratosYYYY.xlsx`, one sheet `Sheet1` each)
- Conversion: DuckDB `read_xlsx(all_varchar=true)` → Parquet zstd, one file per year. Every column is text, no casting. Row counts equal the sheet rows minus the header.
- Note: date columns (`dataPublicacao`, `dataCelebracaoContrato`, `dataDecisaoAdjudicacao`, `dataFechoContrato`) come out as Excel serial numbers stored as text (e.g. `43467` = 2019-01-01; date = 1899-12-30 + n days). Amounts use `.` as decimal separator. Some text has HTML entities (`&amp;`).
- `Ano` equals the file's year, but `dataPublicacao`/`dataCelebracaoContrato` can fall in earlier years (the first 2019 row has `dataPublicacao` 43103 = 2018-01-03). Check this before choosing the year to analyse by.
- Not downloaded (same publisher, separate datasets): announcements https://dados.gov.pt/pt/datasets/66d72fbc58cd7a63dae28712/ (anunciosYYYY.xlsx/json), contract modifications https://dados.gov.pt/pt/datasets/668d65dbcb1b953e80198435/, entities https://dados.gov.pt/pt/datasets/67d80b2c4750b888116940fb/.
