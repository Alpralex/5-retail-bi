How the numbers are built

  • Data: the public M5 Forecasting dataset (Walmart, 2020): daily unit sales for 3,049 items in 10 stores in California, Texas and Wisconsin, weekly shelf prices and a calendar. The forecast is the published submission of the competition winner.
  • Model: dbt on DuckDB. Staging views unpivot the wide CSVs; marts form a star schema (dim_date, dim_item, dim_store, fct_sales_daily, fct_forecast_eval) with tests for keys, relationships, accepted values and row counts.
  • WAPE = sum of absolute errors ÷ sum of actual units. Bias = (forecast − actual) ÷ actual. MAPE is not used because most item-days sell zero units.
  • Suspected stock-out: M5 has no inventory data. A run of 7 to 56 days with zero sales, for an item that averages 2 or more units a day, is treated as an empty shelf. Lost units = run length × the item's average daily units; lost revenue uses its average price. This is an estimate, not a measured loss.
